# Documentation

La documentation du projet est séparée en deux espaces.

## `conception`

Liaison locale vers la documentation existante du projet **24** dans Google Drive synchronisé.

Ce dossier n'est **pas versionné dans Git**. Utilisez `../scripts/link-conception.ps1` depuis la racine du projet pour créer la liaison sur chaque poste.

## `dev`

Documentation Markdown versionnée avec le futur code source de l'application.

Elle contient uniquement les éléments nécessaires à la conception technique, au développement, aux tests et à l'exploitation de l'application.
